## :dart: O guia para alavancar a sua carreira

> Angular é um framework completo mantido pelo Google para construir aplicações web robustas: componentes, injeção de dependência, roteamento, formulários e cliente HTTP já vêm integrados, com TypeScript como linguagem padrão desde o primeiro dia. É a escolha mais comum em times enterprise e bancos no Brasil, justamente pela estrutura opinativa e pelo suporte de longo prazo do Google. Este guia reúne roadmap, cursos gratuitos e pagos, documentação oficial, livros, canais, ferramentas do ecossistema (NgRx, Angular Material, Nx, Signals), comunidades e um capítulo dedicado a usar IA na prática com Angular — tudo verificado e organizado para quem já sabe o básico de JavaScript/TypeScript e quer sair do primeiro `ng generate component` até dominar Signals, SSR e arquitetura standalone.

## 🤖 IA na prática

Angular tem uma característica que muda como você usa IA: o framework é bem mais opinativo que outros frameworks front-end (CLI própria, injeção de dependência, decorators, e agora Signals), então a IA erra menos em "estrutura" e mais em "versão" — sugerindo padrões antigos (NgModules, RxJS para tudo) em vez das APIs modernas (standalone components, Signals, novo control flow). O próprio time do Angular já publicou orientação oficial sobre isso.

**Para aprender**

- Leia o [guia oficial "Develop with AI"](https://angular.dev/ai/develop-with-ai) do time do Angular: explica como usar assistentes de IA sem cair nas armadilhas mais comuns do framework.
- Peça para a IA **explicar a diferença entre um componente com NgModule e um componente standalone** colando um exemplo de cada — ajuda a entender por que a API standalone é hoje a forma recomendada.
- Cole um trecho de código usando `@Input`/`@Output` decorators e peça para a IA reescrever usando `input()` e `output()` (as novas funções baseadas em Signals), explicando a diferença.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (Signals, injeção de dependência, formulários reativos, roteamento com lazy loading).

**Para trabalhar**

- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para: gerar componentes a partir de uma descrição, escrever testes unitários, migrar componentes com NgModule para standalone e criar variações de UI com [Angular Material](https://material.angular.dev/) ou [PrimeNG](https://primeng.dev/).
- O Angular disponibiliza um [servidor MCP oficial](https://angular.dev/ai/mcp) que dá a assistentes de IA acesso a contexto atualizado da documentação e das melhores práticas do framework — configure-o na sua ferramenta de IA para reduzir alucinações de API.
- Depois de **cada** sugestão aceita, rode o `ng lint` (com [Angular ESLint](https://github.com/angular-eslint/angular-eslint)) e os testes. Se o código gerado ainda usa `NgModule`, `*ngIf`/`*ngFor` (em vez do novo `@if`/`@for`) ou RxJS onde um Signal bastaria, provavelmente é sugestão desatualizada.
- Use a IA para gerar `ng generate schematics` customizados quando seu time tem padrões próprios de componente — economiza bastante boilerplate repetitivo.

**Limites e boas práticas**

- IA **mistura sintaxes de versões diferentes do Angular** com frequência (ex.: código do AngularJS antigo, `*ngIf` misturado com `@if`, decorators de Input/Output misturados com `input()`/`output()`). Confirme sempre na [documentação oficial](https://angular.dev/).
- Ela costuma sugerir `Subscription` manual e `ngOnDestroy` onde o `async` pipe ou `toSignal()` resolveriam com menos código e sem risco de memory leak.
- Cuidado com sugestões de bibliotecas de estado: a IA às vezes recomenda NgRx para casos simples que um `signal()` local já resolveria — avalie a complexidade real antes de aceitar.
- Não cole código proprietário, chaves de API ou dados de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

## 💼 Carreira e vagas

Angular é forte em vagas de empresas maiores, bancos, fintechs e times enterprise no Brasil — muitas vagas pedem também RxJS, NgRx e TypeScript avançado. Dica: nos repositórios de vagas do GitHub abaixo, pesquise por "Angular" nas issues abertas.

- [State of JS 2024](https://2024.stateofjs.com/en-US/) — Pesquisa anual sobre o ecossistema JS, com seção dedicada à adoção e satisfação com o Angular.
- [Stack Overflow Developer Survey 2025](https://survey.stackoverflow.co/2025/) — Angular segue entre os frameworks mais usados profissionalmente no mundo.
- [frontendbr/vagas](https://github.com/frontendbr/vagas) — Vagas de front-end publicadas como issues no GitHub — muitas pedem Angular.
- [Programathor — vagas Angular](https://programathor.com.br/jobs-angular) — Vagas de tecnologia no Brasil filtradas por Angular.
- [GeekHunter](https://www.geekhunter.com.br/) — Plataforma brasileira onde empresas fazem propostas diretas a devs Angular.
- [Remotar](https://remotar.com.br/) — Vagas 100% remotas para desenvolvedores brasileiros, muitas de front-end/Angular.
- [RemoteOK — vagas Angular](https://remoteok.com/remote-angular-jobs) — Vagas remotas internacionais filtradas por Angular.

## 👥 Comunidades

- [Angular Brasil (Telegram)](https://t.me/angularbrasil) — Grupo brasileiro no Telegram para devs Angular trocarem dúvidas e vagas.
- [Angular Community (Discord)](https://discord.com/invite/angular) — Comunidade internacional no Discord para discutir Angular, tirar dúvidas e acompanhar novidades.
- [r/Angular2 (Reddit)](https://www.reddit.com/r/Angular2/) — Subreddit da comunidade Angular, com discussões, dúvidas e novidades.
- [DEV Community — tag Angular](https://dev.to/t/angular) — Artigos e discussões sobre Angular publicados pela comunidade internacional.
- [TabNews](https://www.tabnews.com.br/) — Comunidade brasileira de conteúdo técnico criada por Filipe Deschamps, com discussões de front-end.
- [He4rt Developers](https://heartdevs.com/) — Comunidade brasileira open source com Discord ativo e projetos usando diversas stacks, incluindo Angular.
- [Angular — GitHub Discussions](https://github.com/angular/angular/discussions) — Espaço oficial onde o time do Angular discute publicamente dúvidas, RFCs e as próximas versões com a comunidade.

## 🎓 Certificações

Não existe uma certificação "oficial" única do Angular mantida pelo Google como pré-requisito de mercado — o que mais conta ainda são projetos publicados e domínio prático. Os certificados abaixo ajudam no currículo:

- [IBM Full-Stack Cloud Developer Professional Certificate (Coursera)](https://www.coursera.org/professional-certificates/ibm-full-stack-cloud-developer) — Certificado profissional pago da IBM que inclui Angular entre as tecnologias de front-end ensinadas.
- [Learn Angular — certificado (Codecademy)](https://www.codecademy.com/learn/learn-angular) — Curso interativo com certificado de conclusão disponível no plano pago (Codecademy Pro).
